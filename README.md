# acca
`acca` is a simple source code editor for Windows.
The project focuses on simplicity and performance;
`acca` is designed to be minimalistic and require
close to no effort to learn and install, allowing
users to start writing code without distractions.

## Build
Instructions assume MinGW via MSYS2 on MS Windows.
A link to a tutorial by Microsoft is given below:
https://code.visualstudio.com/docs/cpp/config-mingw

1. Clone the repository/download it as a zip file.
2. Run the following command in the project folder:

    make

3. Locate the binary `acca.exe` in the working dir.
